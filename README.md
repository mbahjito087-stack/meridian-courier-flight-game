Meridian Courier is a complete flight game: fly a bush plane down a river valley, thread golden rings, mind your fuel, and bring her home to land on Meridian Field. Three sorties, a real flight model with stalls and landings, lit cockpit instruments, and synthesised engine sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network request, desktop Chrome. Arrows or WASD fly, W / S work the throttle, F flaps, G gear, A autopilot, P pause, M sound. Or open `game/index.html` straight from the files.
